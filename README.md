# Калькулятор электронщика

Сайт: https://dofam1n14.github.io/kalkulyator/

Калькуляторы для электроники в одной странице:

- цветовая маркировка резисторов (3–6 полос) и SMD-маркировка;
- закон Ома с интерактивным кругом формул, соединение резисторов, сопротивление провода;
- делитель напряжения, RC-фильтр, резистор для светодиода, таймер NE555;
- перевод единиц: дБ/дБм, частота и длина волны, мм/mil/дюймы.

Сделано вайб-кодингом вместе с Claude.
